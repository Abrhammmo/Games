
**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`


🎮 Games Collection (React + TypeScript)

A mini collection of classic games built using React, TypeScript, and Vite. The project demonstrates modular game development, component reusability, state management, and clean UI structure.

**🚀 Features**

🎯 Multiple games in one project

🧩 Built using React + TypeScript + Vite

⚡ Fast development & build performance with Vite

🗂️ Component-based and scalable structure

🔥 Firebase ready (authentication, database, or analytics)

💡 Easy to extend — plug in more games anytime

**🧰 Tech Stack**
Technology	Purpose
React	UI & component structure
TypeScript	Strong typing & maintainability
Vite	Fast build + development server
Firebase	Backend services (optional)
🛠️ Installation & Setup
clone the repository
git clone <your-repo-url>

Navigate to the project folder
cd <project-folder>

Install dependencies
npm install

Run the development server
npm run dev

**📦 Build for ProductionZ**
npm run build


To preview:

npm run preview

**🔥 Firebase Configuration**

Add your Firebase configuration keys inside .env.local:

VITE_FIREBASE_API_KEY=your_key
VITE_FIREBASE_AUTH_DOMAIN=your_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
...


Make sure .env.local stays hidden in version control (already listed in .gitignore).
